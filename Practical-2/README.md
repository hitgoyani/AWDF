## 📌 Objective
To introduce client-side multi-page routing with React Router v6 (`BrowserRouter`, `Routes`, `Route`, `NavLink`) and handle application state using React's `useState` hook (controlled form inputs, tooltip toggles, character counts, theme switching, and 404 page handling).

---

## 📁 Routes Architecture
- `/` $\rightarrow$ `Home.jsx` (`About` + `Skills`)
- `/projects` $\rightarrow$ `Projects.jsx` (Hardcoded featured projects list)
- `/contact` $\rightarrow$ `Contact.jsx` (Controlled text input with character count & toggle tooltip)
- `*` $\rightarrow$ `NotFound.jsx` (Custom 404 Catch-all route)
