## 📌 Objective
To set up a React development environment using Vite and build a static student portfolio UI using independently structured, reusable components (`Header`, `About`, `Skills`, `Footer`).

---

## 📁 Component Tree
```text
App.jsx
├── Header.jsx (site title, student name, theme color prop)
├── About.jsx (short bio text)
├── Skills.jsx (renders skill list dynamically from props)
└── Footer.jsx (contact email & copyright info)
```

---

## 🚀 How to Run
```bash
npm install
npm run dev
```
